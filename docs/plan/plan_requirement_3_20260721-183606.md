## 总体验收标准

- **验收命令**：无特定命令，需人工审核生成的报表文件
- **验收范围**：整个项目的代码质量分析结果
- **通过标准**：
  1. 报表包含 ESLint 分析、TypeScript 类型检查、测试覆盖率、代码复杂度、依赖安全 5 个维度
  2. 每个维度有具体的数据统计和问题列表
  3. 报表有综合评分或优先级排序
  4. 报表格式清晰，可读性强
  5. 所有分析数据与实际运行结果一致
