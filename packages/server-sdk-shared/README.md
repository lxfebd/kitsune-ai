# @kitsune/server-sdk-shared

Shared event contracts and types for Kitsune server SDK consumers and server-side handlers.

## Usage

```shell
ni @kitsune/server-sdk-shared -D
pnpm i @kitsune/server-sdk-shared -D
```

```typescript
import type { WireMessage } from '@kitsune/server-sdk-shared'

import { newMessages, pullMessages, sendMessages } from '@kitsune/server-sdk-shared'
```
